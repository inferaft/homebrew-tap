# Inferaft Homebrew tap

Install Inferaft Code on macOS Apple Silicon:

```sh
brew install inferaft/tap/inferaft-code
```

Create an API key at https://inferaft.com/dashboard/keys and set `INFERAFT_API_KEY` in your shell. Then run:

```sh
inferaft doctor
inferaft
```

Homebrew installs Node.js 24 as a dependency. This is the 0.1 preview for Apple Silicon Macs. Releases and checksums are listed at https://github.com/inferaft/homebrew-tap/releases.
